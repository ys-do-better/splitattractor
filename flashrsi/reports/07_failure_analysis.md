# 已观察的问题与处理

1. 历史适配以 DSH 为 Target，缺少通用的 MiniAgent 轨迹和用量。新适配走
   共同的 MiniAgent 路径，并由宿主记录模型调用返回的 usage。
2. 容器版原路径需要运行时下载依赖。新路径使用宿主 Python 运行相同
   MiniAgent ReAct 循环，Shell 在 Harbor 容器内执行，绕开额外容器依赖安装。
3. 离线检索发现 FlashRSI 的全限定任务 ID 与原生库的短 ID 不同。
   已在适配层转换并由 K1/K2 测试覆盖。
4. 原生 K20 只有稳定层。适配器在临时快照中记录全量 215 个原子为慢层，
   快层为空。原始 K20 包不写入。CLS K28 与 K29 直接保留各自分层。
5. 真实 DeepSeek MiniAgent 冒烟的外部任务上下文传输未通过自动审批。
   已完成无外传的替代工程检查，性能对比仍缺实际运行记录。
